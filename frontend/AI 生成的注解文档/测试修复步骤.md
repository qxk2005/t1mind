## 🗑️ 手动清理配置数据库（终极方案）

如果上述方法都不行，可以手动删除配置数据库：

```bash
# 1. 关闭应用

# 2. 找到配置数据库位置（通常在用户目录下的 AppFlowy 数据文件夹）
# macOS: ~/Library/Application Support/com.appflowy.app/
# 查找名为 cache.db 的文件

# 3. 备份数据库（可选）
cp ~/Library/Application\ Support/com.appflowy.app/cache.db ~/cache.db.backup

# 4. 删除数据库
rm ~/Library/Application\ Support/com.appflowy.app/cache.db

# 5. 重新启动应用（会自动创建新的数据库）
```

**注意**：删除 cache.db 会清除所有本地配置，包括：
- 网络搜索供应商
- AI 设置
- MCP 服务器配置
- 其他缓存的配置数据
