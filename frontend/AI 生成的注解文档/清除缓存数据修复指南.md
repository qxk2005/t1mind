# 清除缓存数据修复指南

## 问题根源

找到了问题的真正原因！有两个缓存数据库文件包含损坏的网络搜索配置数据：

```
/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data_beta.appflowy.cloud/cache.db
/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data/cache.db
```

即使我们修复了 Rust 代码，这些损坏的缓存数据仍然会导致 `InvalidProtocolBufferException`。

## 解决方案

### 方案 1：完全清除缓存（推荐）

**步骤 1：关闭应用**
```bash
# 确保 AppFlowy 应用完全关闭
pkill -f "AppFlowy"
```

**步骤 2：备份并清除缓存**
```bash
# 创建备份目录
mkdir -p ~/Desktop/appflowy_cache_backup

# 备份现有缓存
cp "/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data_beta.appflowy.cloud/cache.db" ~/Desktop/appflowy_cache_backup/
cp "/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data/cache.db" ~/Desktop/appflowy_cache_backup/

# 删除损坏的缓存文件
rm "/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data_beta.appflowy.cloud/cache.db"
rm "/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data/cache.db"
```

**步骤 3：重新启动应用**
```bash
cd /Users/niuzhidao/Documents/Program/t1mind/frontend/appflowy_flutter
flutter run
```

### 方案 2：选择性清除网络搜索配置

如果你不想丢失其他配置，可以只清除网络搜索相关的配置：

**步骤 1：关闭应用**
```bash
pkill -f "AppFlowy"
```

**步骤 2：使用 SQLite 清除特定配置**
```bash
# 安装 sqlite3（如果没有）
brew install sqlite3

# 清除网络搜索配置
sqlite3 "/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data_beta.appflowy.cloud/cache.db" "DELETE FROM kv_table WHERE key LIKE '%web_search%';"

sqlite3 "/Users/niuzhidao/Library/Application Support/com.appflowy.appflowy.flutter/data/cache.db" "DELETE FROM kv_table WHERE key LIKE '%web_search%';"
```

**步骤 3：重新启动应用**
```bash
cd /Users/niuzhidao/Documents/Program/t1mind/frontend/appflowy_flutter
flutter run
```

## 验证修复

1. **网络搜索设置页面正常加载**
2. **不再出现 "加载全局配置异常" 错误**
3. **可以正常添加搜索供应商**

- ✅ 可以添加新的搜索供应商

## 如果问题仍然存在

如果清除缓存后问题仍然存在，请：

1. **检查日志**：查看是否还有其他错误
2. **重新编译**：确保使用最新的 Rust 库
3. **完全重启**：重启整个开发环境

## 重要说明

- 清除缓存会重置所有配置，但不会影响你的文档数据
- 建议先备份缓存文件以防万一
- 修复后，应用会重新创建干净的配置
