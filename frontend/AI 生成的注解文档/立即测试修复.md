## 📊 修复原理

### 问题根源
旧代码在配置损坏时返回错误响应，但错误响应本身的 Protocol Buffer 序列化也失败了，导致 Flutter 无法解析。

### 解决方案
修改后的代码：
```rust
// ❌ 旧代码 - 返回错误
let providers = web_search_hub.get_provider_list().await?;

// ✅ 新代码 - 捕获错误并返回默认值
let providers = match web_search_hub.get_provider_list().await {
    Ok(list) => list,
    Err(e) => {
        info!("Failed to get provider list, returning empty list: {}", e);
        return data_result_ok(WebSearchProviderListPB { providers: vec![] });
    }
};
```

这样即使配置损坏，Flutter 也会收到有效的空列表响应，而不是无法解析的错误。
