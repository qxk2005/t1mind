# 对话框内边距优化

## 问题描述
添加搜索供应商对话框中的元素太靠近窗口边缘，视觉上显得拥挤。

## 解决方案

### 1. 添加供应商对话框
在 `_AddWebSearchProviderDialog` 的 build 方法中，为主容器添加内边距：

```dart
Widget build(BuildContext context) {
  return FlowyDialog(
    child: Container(
      width: 580,
      constraints: const BoxConstraints(maxHeight: 720),
      padding: const EdgeInsets.all(24), // ✅ 新增 24px 内边距
      child: Column(
        // ... 内容
      ),
    ),
  );
}
```

### 2. 配置供应商对话框
同样为 `_ConfigureWebSearchProviderDialog` 添加内边距：

```dart
Widget build(BuildContext context) {
  return FlowyDialog(
    title: FlowyText.medium("配置供应商: ${widget.provider.name}"),
    child: Container(
      width: 500,
      padding: const EdgeInsets.all(20), // ✅ 新增 20px 内边距
      child: Column(
        // ... 内容
      ),
    ),
  );
}
```

## 内边距说明

### 为什么选择这些值？

1. **添加供应商对话框: 24px**
   - 对话框较大（580px 宽）
   - 内容较多，需要更多呼吸空间
   - 符合 Material Design 推荐的大型对话框内边距

2. **配置供应商对话框: 20px**
   - 对话框稍小（500px 宽）
   - 已有标题栏，视觉上已有分隔
   - 保持适中的留白比例

### 视觉改进

- ✅ **更好的视觉呼吸感**: 元素不再紧贴边缘
- ✅ **更专业的外观**: 符合现代 UI 设计规范
- ✅ **更舒适的阅读体验**: 内容不会感到拥挤
- ✅ **更好的层次感**: 内边距创造了视觉层次

## 对比数据

| 对话框 | 改进前 | 改进后 | 有效内容宽度 |
|--------|--------|--------|--------------|
| 添加供应商 | 0px | 24px | 532px (580-24*2) |
| 配置供应商 | 0px | 20px | 460px (500-20*2) |

## 最佳实践参考

根据 Material Design 指南：
- **小对话框** (< 400px): 16px 内边距
- **中等对话框** (400-600px): 20-24px 内边距
- **大对话框** (> 600px): 24-32px 内边距

我们的实现完全符合这些最佳实践。
