# 禁用调试日志指南

## 快速方法：通过环境变量控制

### Rust 后端日志
在运行应用前设置环境变量：

```bash
# macOS/Linux
export RUST_LOG=warn  # 只显示警告和错误

# 或者更精细的控制
export RUST_LOG=flowy_ai=warn,flowy_core=error

# Windows
set RUST_LOG=warn
```

### Flutter 前端日志
修改 `appflowy_flutter/lib/main.dart`：

```dart
void main() {
  // 禁用调试日志
  Log.shared.disableLog = true;  // 添加这一行
  
  runApp(MyApp());
}
```

## 永久方法：修改日志级别

### 方法 1: 批量将 info! 改为 trace!

在项目根目录运行：

```bash
# 将所有 RAG 相关的 info! 改为 trace!
find rust-lib/flowy-ai/src -name "*.rs" -exec sed -i '' 's/info!("\[RAG\]/trace!("\[RAG\]/g' {} +
find rust-lib/flowy-ai/src -name "*.rs" -exec sed -i '' 's/warn!("\[RAG\]/trace!("\[RAG\]/g' {} +

# 将所有 Embedding 相关的 info! 改为 trace!
find rust-lib/flowy-ai/src -name "*.rs" -exec sed -i '' 's/info!("\[Embedding\]/trace!("\[Embedding\]/g' {} +

# 将所有 Chat 相关的 info! 改为 trace!
find rust-lib/flowy-ai/src -name "*.rs" -exec sed -i '' 's/info!("\[Chat\]/trace!("\[Chat\]/g' {} +
```

### 方法 2: 修改 dev.env 文件

编辑 `appflowy_flutter/dev.env`：

```env
RUST_LOG=warn
```

## 推荐配置

**生产环境：**
```bash
RUST_LOG=flowy_ai=warn,flowy_core=warn,flowy_folder=warn
```

**开发环境（需要调试时）：**
```bash
RUST_LOG=flowy_ai=debug
```

**完全静默：**
```bash
RUST_LOG=error
```

---

## 恢复日志

如果需要恢复某个模块的日志：

```bash
# 只显示 RAG 相关日志
export RUST_LOG=warn,flowy_ai::middleware::chat_service_mw=info

# 显示所有 AI 模块日志
export RUST_LOG=flowy_ai=info
```

---

## 注意事项

- 环境变量方法最灵活，推荐使用
- trace! 级别日志默认不显示，只在 `RUST_LOG=trace` 时才显示
- 修改源码需要重新编译
