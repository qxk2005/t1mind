# 问题气泡设置功能完成总结

## 功能概述
成功为AppFlowy添加了全局设置选项，允许用户控制右下角"？"图标悬浮按钮的显示/隐藏。

## 实现的功能
1. **全局设置控制**：用户可以在设置中开启/关闭问题气泡的显示
2. **实时生效**：设置更改后立即生效，无需重启应用
3. **多语言支持**：支持中文和英文界面
4. **移动端支持**：在移动端设置界面中添加了相应的开关选项

## 技术实现细节

### 数据流
1. 用户在设置界面切换开关
2. `AppearanceSettingsCubit.setShowQuestionBubble()`被调用
3. 设置保存到后端
4. `AppearanceSettingsState`更新
5. `QuestionBubble`组件重新渲染，根据新状态显示/隐藏

### 状态管理
- 使用Flutter Bloc模式管理状态
- 设置持久化到后端存储
- 状态变化实时反映到UI

### 兼容性
- 默认值为`true`，确保现有用户不受影响
- 向后兼容，不会破坏现有功能

## 使用方法

### 桌面端
1. 打开AppFlowy应用
2. 进入设置 → 工作区设置
3. 在"文本方向"部分找到"显示帮助气泡"选项
4. 切换开关来控制问题气泡的显示/隐藏

### 移动端
1. 打开AppFlowy应用
2. 进入设置 → 外观设置
3. 找到"显示帮助气泡"选项
4. 切换开关来控制问题气泡的显示/隐藏

**注意**：该设置同时支持桌面端和移动端，设置会同步保存。
