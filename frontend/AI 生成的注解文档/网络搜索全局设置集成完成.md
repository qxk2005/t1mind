创建了 `SettingsWebSearchView` 组件，用于在全局设置中显示网络搜索配置：

```dart
class SettingsWebSearchView extends StatelessWidget {
  const SettingsWebSearchView({
    super.key,
    required this.userProfile,
    required this.workspaceId,
  });

  final UserProfilePB userProfile;
  final String workspaceId;

  @override
  Widget build(BuildContext context) {
    return BlocProvider<WebSearchSettingsBloc>(
      create: (_) => WebSearchSettingsBloc()
        ..add(const WebSearchSettingsEvent.started()),
      child: SettingsBody(
        title: "网络搜索配置",
        description: "配置网络搜索引擎供应商和全局设置",
        children: const [
          WebSearchSettingsContent(),
        ],
      ),
    );
  }
}
```

## 用户体验

现在用户可以：

1. **打开全局设置**：点击设置按钮
2. **找到网络搜索选项**：在设置菜单中看到"网络搜索"选项（带搜索图标）
3. **配置网络搜索**：
   - 添加/编辑/删除搜索引擎供应商（Tavily、Brave Search）
   - 配置 API 密钥
   - 测试连接
   - 启用/停用供应商
   - 配置全局搜索设置（最大结果数、超时时间、缓存等）
   - 查看和清理缓存统计

## 技术实现

### 架构设计

1. **分离关注点**：
   - `WebSearchSettingsBloc` - 业务逻辑和状态管理
   - `WebSearchSettingsContent` - UI 组件（供应商列表、全局配置、缓存管理）
   - `SettingsWebSearchView` - 全局设置页面包装器

2. **复用组件**：
   - 使用 `SettingsBody` 提供统一的设置页面布局
   - 使用 `SettingsMenuElement` 添加菜单项
   - 复用现有的 BLoC 模式和状态管理

3. **一致性**：
   - 遵循现有的设置页面模式（AI、MCP、Agent）
   - 使用相同的布局和样式
   - 保持用户体验一致
