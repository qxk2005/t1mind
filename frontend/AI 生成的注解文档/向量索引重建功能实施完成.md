为 AppFlowy AI 设置页面添加了完整的向量索引重建功能，允许用户主动控制文档索引过程，实时查看进度和日志。

### 1. 后端实现 (Rust)

#### 1.1 Protobuf 定义
📁 **文件修改：**
- `rust-lib/flowy-ai/resources/proto/event_map.proto`
- `rust-lib/flowy-ai/resources/proto/entities.proto`
- `rust-lib/flowy-ai/resources/proto/notification.proto`

**新增事件：**
- `RebuildVectorIndex` (68) - 重建向量索引
- `GetVectorIndexStatus` (69) - 获取索引状态
- `StopVectorIndexing` (70) - 停止索引

**新增消息类型：**
- `VectorIndexStatusPB` - 索引状态（状态、进度、日志、错误）
- `VectorIndexStatePB` - 索引状态枚举（空闲/运行/完成/失败/停止中）
- `RebuildVectorIndexRequestPB` - 重建请求
- `RebuildVectorIndexResponsePB` - 重建响应

**新增通知：**
- `VectorIndexStatusUpdated` (10) - 状态更新通知

#### 1.2 核心索引管理器
📁 **新建文件：** `rust-lib/flowy-ai/src/vector_index_manager.rs`

**核心功能：**
- ✅ 异步后台索引执行
- ✅ 实时进度跟踪（总文档数 / 已索引数）
- ✅ 详细日志记录（最多保留 50 条）
- ✅ 支持停止操作
- ✅ 错误处理和恢复
- ✅ 自动状态通知

**关键特性：**
- 使用 `Arc` 和 `RwLock` 确保线程安全
- 使用 `AtomicU32` 和 `AtomicI64` 实现无锁计数器
- 使用 `tokio::spawn` 实现真正的后台执行
- 每个文档间隔 100ms 避免过载

#### 1.3 事件处理集成
📁 **文件修改：**
- `rust-lib/flowy-ai/src/event_handler.rs` - 添加 3 个事件处理函数

- `rust-lib/flowy-ai/src/ai_manager.rs` - 集成索引管理器
- `rust-lib/flowy-core/src/deps_resolve/chat_deps.rs` - 传递 FolderService

## 🎨 用户体验设计

### 功能流程

```
1. 用户打开 AI 设置页面
   ↓
2. 看到"向量索引管理"区域
   ↓
3. 点击"重建向量索引"按钮
   ↓
4. 实时看到：
   - 进度条更新（X/Y 个文档）
   - 百分比显示
   - 详细日志滚动
   ↓

   - 关闭设置页面（索引继续）

6. 完成后显示：

   - 最终统计信息
```

### 状态反馈

| 状态 | 视觉效果 | 用户操作 |
|------|---------|---------|
| 空闲 | 灰色文本 | 可以开始重建 |
| 运行中 | 蓝色进度条 + 动画 | 可以停止 |
| 完成 | 绿色勾选 | 可以再次重建 |
| 失败 | 红色错误提示 | 可以重试 |
| 停止中 | 灰色 | 等待停止 |

## 🔧 技术亮点

### 1. 后台执行架构
```rust
// 使用 tokio::spawn 实现真正的后台任务
tokio::spawn(async move {
  // 索引逻辑...
  // 即使前端关闭，任务仍然继续
});
```

### 2. 无阻塞状态更新
```rust
// 使用原子操作更新计数器
indexed_documents.fetch_add(1, Ordering::Relaxed);

// 使用 RwLock 管理共享状态
*self.state.write().await = VectorIndexState::Running;
```

### 3. 实时通知机制
```rust
// 后端发送通知
chat_notification_builder("", ChatNotification::VectorIndexStatusUpdated)
  .send();

// 前端监听通知
_notificationParser.stream.listen((notification) {
  add(VectorIndexEvent.statusUpdated(notification));
});
```

### 4. 智能日志管理
```rust
// 自动限制日志数量
if logs.len() > Self::MAX_LOGS {
  logs.drain(0..(logs.len() - Self::MAX_LOGS));
}
```
