# 网络搜索配置问题修复完成

## 问题概述

全局设置的网络搜索设置页面出现以下问题：
1. 搜索供应商列表报错异常（InvalidProtocolBufferException: Protocol message）
2. 全局配置和缓存管理一直转圈圈，无法加载

## 问题根源分析

通过全面排查后发现，问题出在 `event_handler.rs` 中有三个事件处理器被临时修改为返回空数据/默认数据，而不是调用实际的实现：

### 1. 获取供应商列表处理器
```rust
// 之前的代码（错误）
pub(crate) async fn get_web_search_provider_list_handler(...) {
    let ai_manager = upgrade_ai_manager(ai_manager)?;
    
    // 直接返回空列表，绕过了实际实现
    info!("Returning empty web search provider list to avoid ProtoBuf parsing errors");
    data_result_ok(WebSearchProviderListPB { providers: vec![] })
}
```

### 2. 获取全局配置处理器
```rust
// 之前的代码（错误）
pub(crate) async fn get_web_search_global_config_handler(...) {
    let ai_manager = upgrade_ai_manager(ai_manager)?;
    
    let web_search_hub = match ai_manager.get_web_search_hub().await {
        Ok(hub) => hub,
        Err(e) => {
            return data_result_ok(WebSearchGlobalConfigPB::default_config());
        }
    };
    
    // 直接返回默认配置，绕过了实际实现
    info!("Returning default web search global config to avoid ProtoBuf parsing errors");
    data_result_ok(WebSearchGlobalConfigPB::default_config())
}
```

### 3. 获取缓存统计处理器
```rust
// 之前的代码（错误）
pub(crate) async fn get_web_search_cache_stats_handler(...) {
    let ai_manager = upgrade_ai_manager(ai_manager)?;
    
    // 直接返回空统计，绕过了实际实现
    info!("Returning default web search cache stats to avoid ProtoBuf parsing errors");
    let response = WebSearchCacheStatsPB {
        total_entries: 0,
        hit_count: 0,
        miss_count: 0,
        hit_rate: 0.0,
        cache_size_bytes: 0,
        last_cleanup_at: None,
    };
    
    data_result_ok(response)
}
```

## 修复方案

修复了三个事件处理器，让它们正确调用 `WebSearchHub` 和 `WebSearchProviderManager` 的实现：

### 1. 修复供应商列表处理器

```rust
pub(crate) async fn get_web_search_provider_list_handler(
    _data: AFPluginData<EmptyRequestPB>,
    ai_manager: AFPluginState<Weak<AIManager>>,
) -> DataResult<WebSearchProviderListPB, FlowyError> {
    let ai_manager = upgrade_ai_manager(ai_manager)?;
    
    let web_search_hub = match ai_manager.get_web_search_hub().await {
        Ok(hub) => hub,
        Err(e) => {
            error!("Failed to get web search hub: {}", e);
            // 返回空列表而不是错误，让UI能够正常显示
            return data_result_ok(WebSearchProviderListPB { providers: vec![] });
        }
    };
    
    let provider_list = web_search_hub.get_provider_list().await?;
    info!("Retrieved {} web search providers", provider_list.providers.len());
    
    data_result_ok(provider_list)
}
```

**关键改进：**
- 调用 `web_search_hub.get_provider_list().await?` 获取真实的供应商列表
- 保留错误处理，确保在失败时返回空列表而不会导致UI崩溃
- 添加日志记录供应商数量

pub(crate) async fn get_web_search_global_config_handler(

### 3. 修复缓存统计处理器

```rust
pub(crate) async fn get_web_search_cache_stats_handler(
    _data: AFPluginData<EmptyRequestPB>,
    ai_manager: AFPluginState<Weak<AIManager>>,
) -> DataResult<WebSearchCacheStatsPB, FlowyError> {
    let ai_manager = upgrade_ai_manager(ai_manager)?;
    
    let web_search_hub = match ai_manager.get_web_search_hub().await {
        Ok(hub) => hub,
        Err(e) => {
            error!("Failed to get web search hub: {}", e);
            // 返回空统计而不是错误，让UI能够正常显示
            let response = WebSearchCacheStatsPB {
                total_entries: 0,
                hit_count: 0,
                miss_count: 0,
                hit_rate: 0.0,
                cache_size_bytes: 0,
                last_cleanup_at: None,
            };
            return data_result_ok(response);
        }
    };
    
    let cache_stats = web_search_hub.get_cache_stats().await?;
    info!("Retrieved web search cache stats: {} entries", cache_stats.total_entries);
    
    use std::time::UNIX_EPOCH;
    
    let response = WebSearchCacheStatsPB {
        total_entries: cache_stats.total_entries as i64,
        hit_count: cache_stats.hits as i64,
        miss_count: cache_stats.misses as i64,
        hit_rate: cache_stats.hit_rate(),
        cache_size_bytes: cache_stats.cache_size_bytes as i64,
        last_cleanup_at: cache_stats.last_cleanup.map(|t| {
            t.duration_since(UNIX_EPOCH).unwrap_or_default().as_secs() as i64
        }),
    };
    
    data_result_ok(response)
}
```

**关键改进：**
- 调用 `web_search_hub.get_cache_stats().await?` 获取真实的缓存统计
- 正确映射字段：`hits` -> `hit_count`, `misses` -> `miss_count`
- 调用 `hit_rate()` 方法计算命中率
- 正确转换 `SystemTime` 为时间戳
- 添加日志记录缓存条目数量
