# 多路召回前端集成说明

## 概述

本文档说明如何在 Flutter 前端集成多路召回功能，包括显示任务分解、并行执行进度和结果综合。

## 已创建的组件

### 1. MultiRetrievalIndicator

位置：`appflowy_flutter/lib/plugins/ai_chat/presentation/message/multi_retrieval_indicator.dart`

这是一个展示多路召回进度的UI组件，包括：
- 任务分解阶段指示
- 并行执行进度条
- 子任务结果列表
- 完成状态

### 2. MultiRetrievalStateManager

状态管理器，用于跟踪每条消息的多路召回状态。

## 集成步骤

### 步骤1：在 ChatAIMessageBloc 中处理多路召回元数据

修改 `chat_ai_message_bloc.dart` 来处理多路召回的元数据：

```dart
// 在 ChatAIMessageState 中添加多路召回状态
class ChatAIMessageState {
  // ... 现有字段 ...
  
  // 🆕 添加多路召回状态
  final MultiRetrievalState? multiRetrievalState;
  
  ChatAIMessageState({
    // ... 现有参数 ...
    this.multiRetrievalState,
  });
  
  ChatAIMessageState copyWith({
    // ... 现有参数 ...
    MultiRetrievalState? multiRetrievalState,
  }) {
    return ChatAIMessageState(
      // ... 现有字段 ...
      multiRetrievalState: multiRetrievalState ?? this.multiRetrievalState,
    );
  }
}

// 在 ChatAIMessageBloc 中处理元数据
void _handleMetadata(Map<String, dynamic> metadata) {
  // 检查是否是多路召回相关元数据
  if (metadata.containsKey('multi_retrieval') || 
      metadata.containsKey('sub_task_result')) {
    
    // 创建或更新多路召回状态
    final currentState = state.multiRetrievalState ?? MultiRetrievalState();
    currentState.updateFromMetadata(metadata);
    
    emit(state.copyWith(
      multiRetrievalState: currentState,
    ));
  }
  
  // ... 处理其他元数据 ...
}
```

### 步骤2：在消息显示中添加多路召回指示器

修改 `ai_text_message.dart` 的 `_NonEmptyMessage` widget：

```dart
class _NonEmptyMessage extends StatelessWidget {
  // ... 现有代码 ...
  
  @override
  Widget build(BuildContext context) {
    return BlocBuilder<ChatAIMessageBloc, ChatAIMessageState>(
      builder: (context, state) {
        return ChatAIMessageBubble(
          message: message,
          // ... 其他参数 ...
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              // 🆕 显示多路召回指示器（如果有）
              if (state.multiRetrievalState != null)
                _buildMultiRetrievalIndicator(state.multiRetrievalState!),
              
              // 推理文本显示
              if (state.reasoningText != null && state.reasoningText!.isNotEmpty)
                _buildReasoningText(context, state),
              
              // 主要消息内容
              _buildMessageContent(context, state),
              
              // 工具调用显示
              if (toolCallsList.isNotEmpty)
                _buildToolCalls(context, toolCallsList),
              
              // 引用来源显示
              if (state.sources.isNotEmpty)
                _buildReferences(context, state),
            ],
          ),
        );
      },
    );
  }
  
  // 🆕 构建多路召回指示器
  Widget _buildMultiRetrievalIndicator(MultiRetrievalState state) {
    return Container(
      margin: const EdgeInsets.only(bottom: 12),
      child: MultiRetrievalCard(state: state),
    );
  }
}
```

### 步骤3：创建 MultiRetrievalCard 组件

创建一个更精美的展示卡片：

```dart
class MultiRetrievalCard extends StatelessWidget {
  final MultiRetrievalState state;

  const MultiRetrievalCard({
    super.key,
    required this.state,
  });

  @override
  Widget build(BuildContext context) {
    return Container(
      padding: const EdgeInsets.all(12),
      decoration: BoxDecoration(
        gradient: LinearGradient(
          colors: [
            Theme.of(context).colorScheme.primaryContainer.withOpacity(0.3),
            Theme.of(context).colorScheme.secondaryContainer.withOpacity(0.3),
          ],
          begin: Alignment.topLeft,
          end: Alignment.bottomRight,
        ),
        borderRadius: BorderRadius.circular(12),
        border: Border.all(
          color: Theme.of(context).colorScheme.outline.withOpacity(0.3),
          width: 1,
        ),
      ),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          // 标题行
          Row(
            children: [
              _buildPhaseIcon(context),
              const SizedBox(width: 8),
              Expanded(
                child: Text(
                  _getPhaseTitle(),
                  style: Theme.of(context).textTheme.titleSmall?.copyWith(
                    fontWeight: FontWeight.w600,
                  ),
                ),
              ),
              if (state.totalTasks > 0)
                _buildProgressChip(context),
            ],
          ),
          
          // 进度条
          if (!state.isCompleted && state.totalTasks > 0) ...[
            const SizedBox(height: 12),
            _buildProgressBar(context),
          ],
          
          // 子任务列表
          if (state.subTaskResults.isNotEmpty) ...[
            const SizedBox(height: 12),
            _buildSubTasksList(context),
          ],
        ],
      ),
    );
  }
  
  Widget _buildPhaseIcon(BuildContext context) {
    IconData icon;
    Color color;
    
    switch (state.currentPhase) {
      case 'decomposition':
        icon = Icons.splitscreen;
        color = Colors.blue;
        break;
      case 'execution':
        icon = Icons.sync;
        color = Colors.orange;
        break;
      case 'synthesis':
        icon = Icons.auto_fix_high;
        color = Colors.purple;
        break;
      case 'completed':
        icon = Icons.check_circle_outline;
        color = Colors.green;
        break;
      default:
        icon = Icons.auto_awesome;
        color = Theme.of(context).colorScheme.primary;
    }
    
    return Container(
      padding: const EdgeInsets.all(6),
      decoration: BoxDecoration(
        color: color.withOpacity(0.15),
        shape: BoxShape.circle,
      ),
      child: Icon(icon, size: 18, color: color),
    );
  }
  
  String _getPhaseTitle() {
    switch (state.currentPhase) {
      case 'decomposition':
        return '🔀 任务分解';
      case 'execution':
        return '⚡ 并行执行';
      case 'synthesis':
        return '🔄 综合结果';
      case 'completed':
        return '✅ 完成';
      default:
        return '🌟 多路召回';
    }
  }
  
  Widget _buildProgressChip(BuildContext context) {
    final color = _getPhaseColor();
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 4),
      decoration: BoxDecoration(
        color: color.withOpacity(0.15),
        borderRadius: BorderRadius.circular(12),
        border: Border.all(color: color.withOpacity(0.3)),
      ),
      child: Text(
        '${state.successCount}/${state.totalTasks}',
        style: Theme.of(context).textTheme.bodySmall?.copyWith(
          color: color,
          fontWeight: FontWeight.w700,
        ),
      ),
    );
  }
  
  Widget _buildProgressBar(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        ClipRRect(
          borderRadius: BorderRadius.circular(4),
          child: LinearProgressIndicator(
            value: state.progress,
            minHeight: 6,
            backgroundColor: Theme.of(context).colorScheme.surfaceVariant,
            valueColor: AlwaysStoppedAnimation<Color>(_getPhaseColor()),
          ),
        ),
        const SizedBox(height: 6),
        Text(
          state.statusText,
          style: Theme.of(context).textTheme.bodySmall?.copyWith(
            color: Theme.of(context).colorScheme.onSurfaceVariant,
          ),
        ),
      ],
    );
  }
  
  Widget _buildSubTasksList(BuildContext context) {
    return Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Text(
          '任务详情',
          style: Theme.of(context).textTheme.bodyMedium?.copyWith(
            fontWeight: FontWeight.w600,
          ),
        ),
        const SizedBox(height: 8),
        ...state.subTaskResults.map((result) {
          return _buildSubTaskItem(context, result);
        }),
      ],
    );
  }
  
  Widget _buildSubTaskItem(BuildContext context, SubTaskResultData result) {
    final iconColor = result.success ? Colors.green : Colors.red;
    
    return Container(
      margin: const EdgeInsets.only(bottom: 6),
      padding: const EdgeInsets.all(10),
      decoration: BoxDecoration(
        color: Theme.of(context).colorScheme.surface.withOpacity(0.5),
        borderRadius: BorderRadius.circular(8),
        border: Border.all(
          color: iconColor.withOpacity(0.2),
          width: 1,
        ),
      ),
      child: Row(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Icon(
            result.success ? Icons.check_circle : Icons.error,
            size: 18,
            color: iconColor,
          ),
          const SizedBox(width: 10),
          Expanded(
            child: Column(
              crossAxisAlignment: CrossAxisAlignment.start,
              children: [
                Text(
                  result.description,
                  style: Theme.of(context).textTheme.bodySmall?.copyWith(
                    fontWeight: FontWeight.w500,
                  ),
                ),
                const SizedBox(height: 4),
                Row(
                  children: [
                    _buildSourceChip(context, result.source),
                    const SizedBox(width: 6),
                    Text(
                      '${result.durationMs}ms',
                      style: Theme.of(context).textTheme.bodySmall?.copyWith(
                        color: Theme.of(context).colorScheme.onSurfaceVariant,
                        fontSize: 11,
                      ),
                    ),
                  ],
                ),
              ],
            ),
          ),
        ],
      ),
    );
  }
  
  Widget _buildSourceChip(BuildContext context, String source) {
    IconData icon;
    Color color;
    String label;
    
    if (source.contains('document_rag')) {
      icon = Icons.description;
      color = Colors.blue;
      label = '文档';
    } else if (source.contains('web_search')) {
      icon = Icons.search;
      color = Colors.orange;
      label = 'Web';
    } else if (source.contains('mcp:')) {
      icon = Icons.extension;
      color = Colors.purple;
      label = 'MCP';
    } else {
      icon = Icons.settings;
      color = Colors.grey;
      label = source;
    }
    
    return Container(
      padding: const EdgeInsets.symmetric(horizontal: 6, vertical: 2),
      decoration: BoxDecoration(
        color: color.withOpacity(0.1),
        borderRadius: BorderRadius.circular(4),
      ),
      child: Row(
        mainAxisSize: MainAxisSize.min,
        children: [
          Icon(icon, size: 12, color: color),
          const SizedBox(width: 4),
          Text(
            label,
            style: Theme.of(context).textTheme.bodySmall?.copyWith(
              color: color,
              fontSize: 10,
              fontWeight: FontWeight.w600,
            ),
          ),
        ],
      ),
    );
  }
  
  Color _getPhaseColor() {
    switch (state.currentPhase) {
      case 'decomposition':
        return Colors.blue;
      case 'execution':
        return Colors.orange;
      case 'synthesis':
        return Colors.purple;
      case 'completed':
        return Colors.green;
      default:
        return Colors.grey;
    }
  }
}
```

## 测试

### 测试场景1：简单问题（不触发多路召回）

```
用户: "文档X的内容是什么？"
预期: 不显示多路召回指示器，直接显示答案
```

### 测试场景2：复杂问题（触发多路召回）

```
用户: "对比我们公司的产品定价策略与市场上主要竞争对手的定价"

预期显示流程:
1. 🔀 任务分解 (1-2秒)
   - "分解为2个子任务"
   
2. ⚡ 并行执行 (2-5秒)
   - 进度条: 0/2 → 1/2 → 2/2
   - 子任务1: ✅ 内部文档检索 (150ms)
   - 子任务2: ✅ Web搜索 (320ms)
   
3. 🔄 综合结果 (1-3秒)
   - "正在综合多个信息源的结果..."
   
4. ✅ 完成
   - 显示完整答案
```

### 测试场景3：部分失败

```
用户: "分析Excel数据并对比行业趋势"

预期显示:
1. ⚡ 并行执行
   - 子任务1: ✅ Excel读取 (200ms)
   - 子任务2: ❌ Web搜索失败 (超时)
   
2. 🔄 综合结果
   - "基于可用的数据分析..."
   - "注: 网络搜索暂时不可用"
```

## 性能优化

1. **避免频繁重建**: 使用 `buildWhen` 只在必要时重建
2. **延迟加载**: 子任务列表默认折叠
3. **缓存计算**: 缓存进度百分比等计算值
