# 修改范围确认说明

## 项目架构澄清

### AppFlowy 不是传统的客户端-服务器架构

AppFlowy 是一个**客户端应用**，采用：
- **Flutter** (前端 UI)
- **Rust** (后端逻辑)
- **本地存储** + **可选的云同步**

**重要说明**：需求文档中提到的"服务器端、移动端、本地端"指的是**配置作用域**，而不是物理的服务器：
- **服务器端设置** = 云端同步的全局设置（AppFlowy Cloud）
- **移动端设置** = 移动平台特定设置
- **本地工作空间设置** = 本地存储的工作空间级别设置
