# 多路召回系统使用示例

## 简介

本文档提供多路召回系统的实际使用示例，包括如何在不同场景下启用和使用这一功能。

## 前提条件

1. 已配置 OpenAI 兼容服务器
2. 智能体系统已启用
3. 至少配置了两种工具（如文档RAG + Web搜索）

## 示例 1：基础多路召回

### 场景

用户询问需要结合内部文档和外部信息的问题。

### 代码示例

```rust
use flowy_ai::middleware::ChatServiceMiddleware;
use flowy_ai::agent::{AvailableTools, ToolCallHandler};
use uuid::Uuid;
use std::sync::Arc;

async fn example_basic_multi_retrieval() -> FlowyResult<()> {
    // 1. 初始化服务
    let chat_service = ChatServiceMiddleware::new(
        user_service,
        cloud_service,
        local_ai,
        storage_service,
        store_preferences,
    );

    // 2. 准备工具处理器
    let tool_handler = Arc::new(ToolCallHandler::new(
        ai_manager.clone(),
        #[cfg(feature = "web-search")]
        web_search_tools,
    ));

    // 3. 构建可用工具列表
    let mut available_tools = AvailableTools::default();
    available_tools.has_document_rag = true;  // 启用文档RAG
    available_tools.has_web_search = true;     // 启用Web搜索

    // 4. 调用多路召回
    let stream = chat_service
        .stream_answer_with_multi_retrieval(
            &workspace_id,
            &chat_id,
            question_id,
            ResponseFormat::Json,
            ai_model,
            Some("You are a helpful assistant.".to_string()),
            tool_handler,
            None,  // 无特定智能体配置
            available_tools,
        )
        .await?;

    // 5. 处理流式响应
    let mut stream_pin = stream;
    while let Some(value) = stream_pin.next().await {
        match value? {
            QuestionStreamValue::Answer { value } => {
                println!("Answer: {}", value);
            }
            QuestionStreamValue::Metadata { value } => {
                println!("Metadata: {:?}", value);
            }
        }
    }

    Ok(())
}
```

### 用户问题示例

```

### 代码示例

async fn example_with_error_handling() -> FlowyResult<()> {
    let stream = chat_service
        .stream_answer_with_multi_retrieval(...)
        .await?;

    let mut stream_pin = stream;
    while let Some(value) = stream_pin.next().await {
        match value {
            Ok(QuestionStreamValue::Metadata { value }) => {
                // 检查子任务执行状态
                if let Some(sub_task) = value.get("sub_task_result") {
                    let success = sub_task.get("success").and_then(|v| v.as_bool());
                    let error = sub_task.get("error");
                    
                    if success == Some(false) {
                        eprintln!("子任务失败: {:?}", error);
                        // 可以选择重试或跳过
                    }
                }
            }
            Ok(QuestionStreamValue::Answer { value }) => {
                println!("Answer: {}", value);
            }
            Err(e) => {
                eprintln!("Stream error: {}", e);
                // 错误处理逻辑
            }
        }
    }

    Ok(())
}
```

## 示例 6：前端集成

### Flutter前端示例

```dart
// 处理多路召回的元数据
void _handleMultiRetrievalMetadata(Map<String, dynamic> metadata) {
  if (metadata.containsKey('multi_retrieval')) {
    final phase = metadata['multi_retrieval']['phase'];
    
    switch (phase) {
      case 'decomposition':
        final taskCount = metadata['multi_retrieval']['sub_tasks_count'];
        _showProgress('任务分解完成：$taskCount 个子任务');
        break;
        
      case 'execution':
        final success = metadata['multi_retrieval']['success_count'];
        final total = metadata['multi_retrieval']['total_tasks'];
        _showProgress('执行进度：$success/$total 完成');
        break;
        
      case 'synthesis':
        _showProgress('正在综合结果...');
        break;
        
      case 'completed':
        _showProgress('多路召回完成！');
        break;
    }
  }
  
  // 处理子任务结果
  if (metadata.containsKey('sub_task_result')) {
    final result = metadata['sub_task_result'];
    _displaySubTaskResult(
      taskId: result['task_id'],
      description: result['task_description'],
      success: result['success'],
      duration: result['duration_ms'],
    );
  }
}

// 显示子任务结果
Widget _buildSubTaskResult(SubTaskResult result) {
  return Card(
    child: ListTile(
      leading: Icon(
        result.success ? Icons.check_circle : Icons.error,
        color: result.success ? Colors.green : Colors.red,
      ),
      title: Text(result.description),
      subtitle: Text('${result.toolUsed} - ${result.durationMs}ms'),
      trailing: result.success 
        ? IconButton(
            icon: Icon(Icons.visibility),
            onPressed: () => _showResultDetail(result),
          )
        : null,
    ),
  );
}
```

## 示例 7：性能监控

### 监控关键指标

```rust
use std::time::Instant;

async fn example_with_monitoring() -> FlowyResult<()> {
    let overall_start = Instant::now();
    
    let stream = chat_service
        .stream_answer_with_multi_retrieval(...)
        .await?;

    let mut metrics = MultiRetrievalMetrics::default();
    let mut stream_pin = stream;
    
    while let Some(value) = stream_pin.next().await {
        match value? {
            QuestionStreamValue::Metadata { value } => {
                // 收集执行指标
                if let Some(phase_data) = value.get("multi_retrieval") {
                    match phase_data.get("phase").and_then(|v| v.as_str()) {
                        Some("execution") => {
                            metrics.parallel_duration_ms = 
                                phase_data.get("duration_ms")
                                    .and_then(|v| v.as_u64())
                                    .unwrap_or(0);
                            metrics.success_count = 
                                phase_data.get("success_count")
                                    .and_then(|v| v.as_u64())
                                    .unwrap_or(0) as usize;
                        }
                        Some("completed") => {
                            metrics.total_duration_ms = 
                                overall_start.elapsed().as_millis() as u64;
                        }
                        _ => {}
                    }
                }
            }
            _ => {}
        }
    }
    
    // 报告指标
    info!("Multi-retrieval metrics: {:?}", metrics);
    
    Ok(())
}

#[derive(Debug, Default)]
struct MultiRetrievalMetrics {
    parallel_duration_ms: u64,
    total_duration_ms: u64,
    success_count: usize,
    failure_count: usize,
}
```

## 故障排查

### 问题1：任务分解失败

**症状**：系统总是返回 `needs_decomposition=false`

**可能原因**：
- AI模型配置问题
- 系统提示词不清晰
- 问题本身确实很简单

**解决方法**：
```rust
// 检查AI配置
let cfg = chat_service.read_openai_compat_chat_config(&workspace_id);
assert!(cfg.is_some(), "OpenAI config not found");

// 启用调试日志
RUST_LOG=flowy_ai::agent::task_decomposer=debug

// 测试任务分解
let decomposer = TaskDecomposer::new(...);
let result = decomposer.decompose(test_question, &tools, None).await?;
debug!("Decomposition result: {:?}", result);
```

### 问题2：工具执行超时

**症状**：某些子任务一直处于pending状态

**可能原因**：
- 工具服务未启动
- 网络连接问题
- 工具执行时间过长

**解决方法**：
```rust
// 添加超时保护
use tokio::time::{timeout, Duration};

let result = timeout(
    Duration::from_secs(30),
    dispatcher.dispatch_parallel(tasks, agent_config)
).await;

match result {
    Ok(Ok(dispatch_result)) => {
        // 成功
    }
    Ok(Err(e)) => {
        error!("Dispatch failed: {}", e);
    }
    Err(_) => {
        error!("Dispatch timeout after 30s");
    }
}
```

### 问题3：结果综合质量差

**症状**：综合的答案不连贯或遗漏信息

**可能原因**：
- 子任务结果质量差
- 综合提示词不够清晰
- AI模型能力限制

**解决方法**：
```rust
// 检查子任务结果
for result in &dispatch_result.results {
    if result.success {
        debug!("Task {} result length: {} chars", 
               result.task_id, result.content.len());
    }
}

// 使用更强大的模型进行综合
let synthesizer = ResultSynthesizer::new(
    cfg.base_url.clone(),
    cfg.api_key.clone(),
    "gpt-4".to_string(),  // 使用更强大的模型
);
```
