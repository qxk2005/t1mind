## 🔧 技术细节

### UnifiedReferenceDisplay组件特性
- **统一的容器样式**：灰色背景、圆角边框
- **统一的标题行**：图标 + 标题 + 计数
- **统一的引用卡片**：
  - 圆形序号（带主题色边框）
  - 白色背景（深色模式下为深灰）
  - 图标 + 文本内容
  - 副标题/说明文本
- **统一的展开/折叠**：默认显示3个，可展开查看全部
- **统一的交互**：InkWell点击效果

### 引用类型处理
```dart
enum ReferenceType {
  webSearch,   // 网络搜索
  document,    // 文档引用
  mcpTool,     // MCP工具
}
```

### 文档名称异步加载
文档引用会异步加载真实的文档名称：
```dart
FutureBuilder<ViewPB?>(
  future: ViewBackendService.getView(ref.id),
  builder: (context, snapshot) {
    // 显示真实的document.name或占位符
  },
)
```
