# 维度不匹配问题解决方案

## 🚨 **问题分析**

从日志可以看出，您遇到了典型的维度不匹配问题：

```
Dimension mismatch for query vector for the "embedding" column. Expected 2560 dimensions but received 1024.
```

**问题原因**：
- 🔍 **查询向量**: 1024维（您的新BGE-M3模型）
- 💾 **数据库存储**: 2560维（之前的Ollama模型）
- ❌ **维度不匹配**: 导致搜索失败

## ✅ **解决方案**

### 1. **立即解决维度不匹配**

使用我们实现的手工指定维度重置功能：

#### **操作步骤**：
1. **进入AI设置页面** → 滚动到底部
2. **点击"手工指定维度"按钮**
3. **输入1024**（BGE-M3模型的维度）
4. **输入"我确认"**
5. **点击"确认手工重置"**

#### **结果**：
- ✅ 向量数据库重建为1024维
- ✅ 解决维度不匹配问题
- ✅ 支持BGE-M3模型搜索

### 2. **新增可配置维度功能**

我已经为您添加了嵌入模型维度配置功能：

#### **新增功能**：
- 🔧 **配置维度**: 在维度显示区域添加"配置维度"按钮
- 💾 **保存配置**: 将维度设置保存到用户配置
- 📏 **实时验证**: 输入验证和错误提示
- 📚 **参考信息**: 包含BGE-M3等常用模型维度

#### **使用方法**：
1. **点击"配置维度"按钮**
2. **输入目标维度**（如：1024）
3. **点击"保存配置"**
