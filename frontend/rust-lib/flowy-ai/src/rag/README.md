# RAG 模块

本模块提供 RAG（检索增强生成）功能的关键组件。

## 模块结构

- `config_manager.rs`: RAG 配置管理器，支持持久化存储和参数验证
- `keyword_retriever.rs`: 关键词检索实现，提供全文搜索能力

## 关键词检索 (Keyword Retriever)

### 当前实现

`SQLiteKeywordStore` 提供了完整的关键词检索功能，**使用完整的 BM25 排名算法**：

1. **检索策略**: 使用完整的 BM25 算法计算相关度分数
2. **查询解析**: 自动将用户查询解析为关键词列表
3. **结果排序**: 按 BM25 分数降序返回结果
4. **数据库集成**: 与 VectorSqliteDB 紧密集成

### ⚠️ 重要说明：不使用 FTS5

**当前实现不使用 SQLite FTS5 扩展**，而是在应用层用纯 Rust 实现 BM25。

**原因**：
- `af_collab_embeddings` 是 vec0 虚拟表，无法直接在其上创建 FTS5 虚拟表
- 应用层实现提供完全控制权，可以灵活调整算法参数
- 避免与 SQLite 特定扩展耦合

**如果将来需要 FTS5 支持**，可以考虑：
1. 创建独立的 FTS5 虚拟表同步数据
2. 或在导入阶段就建立 FTS5 索引

### BM25 算法实现

实现了标准的 BM25 排名算法：

```
score(query, doc) = Σ IDF(qi) * f(qi, doc) * (k1 + 1) / (f(qi, doc) + k1 * (1 - b + b * |d| / avgdl))
```

其中：
- **IDF(qi)**: 逆文档频率 = log((N - df(qi) + 0.5) / (df(qi) + 0.5))
- **f(qi, doc)**: 词 qi 在文档中的频率
- **|d|**: 文档长度（词数）
- **avgdl**: 平均文档长度
- **N**: 总文档数
- **df(qi)**: 包含词 qi 的文档数
- **k1**: 词频饱和度参数（默认 1.5）
- **b**: 长度归一化参数（默认 0.75）

### 功能特性

- ✅ 完整的 BM25 排名算法
- ✅ IDF（逆文档频率）计算
- ✅ 文档频率统计
- ✅ 平均文档长度计算
- ✅ 支持多关键词查询
- ✅ 自动过滤单字符词
- ✅ 按相关度排序
- ✅ 支持工作区过滤
- ✅ 支持对象 ID 过滤

### 当前实现特点

**已实现完整的 BM25 算法**，包括：

1. ✅ **完整的 BM25 公式**: 使用标准 k1=1.5, b=0.75 参数
2. ✅ **IDF 计算**: 标准的逆文档频率公式
3. ✅ **文档频率统计**: 自动计算每个词的文档频率
4. ✅ **平均文档长度**: 动态计算并用于长度归一化
5. ✅ **长度归一化**: 使用 BM25 的标准长度归一化机制
6. ✅ **向量+关键词混合**: 可与向量检索结合用于混合检索
7. ✅ **性能优化**: 高效的内存排序和结果提取

### 未来改进

为了进一步提升性能，可以考虑：

1. **缓存机制**: 缓存文档频率和 IDF 值，避免重复计算
2. **增量更新**: 支持索引的增量更新而非重新加载所有数据
3. **BM25F**: 支持字段级别的 BM25（为不同字段设置不同权重）
4. **并行搜索**: 对于大规模数据集，使用并行搜索提升速度

### 使用示例

```rust
use flowy_ai::rag::{KeywordStore, SQLiteKeywordStore};

let keyword_store = SQLiteKeywordStore::new(vector_db_weak_ref);

// 搜索关键词
let results = keyword_store.search(
    "machine learning",  // 查询
    "workspace-123",       // 工作区 ID
    &vec!["doc-1".to_string(), "doc-2".to_string()],  // 可选的对象 ID 过滤
    10                     // 返回的最大结果数
).await?;
```
