# 安装工具UI实现说明

## 实现状态确认

### ✅ 已实现的功能

#### 1. **弹出窗口显示**
- ✅ 点击"安装缺失组件"按钮时，立即显示进度对话框
- ✅ 对话框尺寸合适（600px宽，最大700px高），不是全屏
- ✅ 对话框使用 `FlowyDialog`，正确显示在屏幕中央

#### 2. **动态更新机制**
- ✅ 对话框使用 `BlocBuilder<ImportSettingsBloc, ImportSettingsState>` 监听状态变化
- ✅ 当 `state.installProgress` 更新时，UI会自动重建
- ✅ 日志、进度条、状态信息都会实时更新

#### 3. **日志累积显示**
- ✅ 使用 `accumulatedLogs` 列表累积所有日志
- ✅ 每次进度更新时，新日志会追加到累积列表中
- ✅ 后端返回的真实日志会合并到累积日志中
- ✅ 日志会按时间顺序显示，不会丢失之前的日志

#### 4. **流式反馈**
- ✅ 安装开始时立即显示初始状态
- ✅ 每3秒更新一次进度（模拟步骤）
- ✅ 显示每个安装步骤的进度和日志
- ✅ 后端返回的真实日志会实时合并显示

#### 5. **UI组件**
- ✅ 安装步骤说明（显示将要执行的步骤）
- ✅ 当前状态显示（带颜色和图标）
- ✅ 进度条（显示百分比）
- ✅ 执行日志区域（可滚动，自动滚动到最新）
- ✅ 操作按钮（根据状态显示不同按钮）

### ⚠️ 当前实现的限制

#### 1. **后端日志更新方式**
- ⚠️ 后端API (`UserEventInstallMissingTools`) 是一次性返回结果的，不是流式的
- ⚠️ 前端使用模拟步骤提供流式反馈，直到后端返回真实结果
- ⚠️ 后端返回的日志会合并到累积日志中，但可能不是实时的

#### 2. **日志更新时机**
- ✅ 模拟步骤：每3秒更新一次（提供流式反馈）
- ⚠️ 后端日志：安装完成后一次性返回（可能延迟）

### 📋 实现细节

#### 对话框实现 (`InstallToolsProgressDialog`)
```dart
// 使用 BlocBuilder 监听状态变化
BlocBuilder<ImportSettingsBloc, ImportSettingsState>(
  builder: (context, state) {
    final progress = state.installProgress;
    // 当 progress 更新时，UI会自动重建
    // 日志会实时显示
    if (progress != null && progress.logs.isNotEmpty) {
      _buildLogsSection(progress.logs); // 显示累积的日志
    }
  },
)
```

#### 日志累积机制 (`_installWithStreamingFeedback`)
```dart
// 累积的日志列表
final accumulatedLogs = <String>[];

// 每次更新时追加新日志
accumulatedLogs.addAll(newLogs);

// 后端返回的日志会合并
mergedLogs.addAll(accumulatedLogs);
mergedLogs.addAll(backendProgress.logs);
```

#### 流式更新流程
1. 点击"安装缺失组件"按钮
2. 立即显示对话框（初始状态）
3. 每3秒更新一次进度（模拟步骤）
4. 日志逐步累积显示
5. 后端返回真实结果后，合并真实日志
6. 显示最终状态（成功/失败）
