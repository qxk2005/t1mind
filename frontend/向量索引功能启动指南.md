## 🐛 常见问题

### Q1: Flutter 代码生成失败
**解决方案：**
```bash
flutter pub get
flutter clean
flutter pub run build_runner build --delete-conflicting-outputs
```

### Q2: 编译错误 - 找不到 VectorIndexStatusPB
**原因：** 后端编译未完成  
**解决方案：** 等待后端编译完成（查看 `cargo` 进程）

### Q3: UI 没有显示索引管理区域
**检查清单：**
1. 确保在 **AI 设置** 页面（不是其他设置）
2. 滚动到页面底部
3. 确保代码已重新编译

### Q4: 点击按钮没有反应
**可能原因：**
1. 后端事件未注册 - 检查 `event_map.rs` 是否重新编译
2. 通知监听失败 - 查看控制台日志
