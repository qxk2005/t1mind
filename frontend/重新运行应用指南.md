## 常见问题排查

### Q1: 看不到DEBUG日志

**解决方案**：
```bash
# 方案A：环境变量
export RUST_LOG=debug,info
flutter run

# 方案B：运行参数
flutter run --dart-define=RUST_LOG=debug

# 方案C：修改launch配置（VSCode）
# 在 .vscode/launch.json 中添加：
{
  "configurations": [
    {
      "args": [
        "--dart-define=RUST_LOG=debug"
      ]
    }
  ]
}
```

### Q2: ProtoBuf错误依然存在

**可能原因**：
- Flutter缓存了旧的库文件
- ProtoBuf插件版本不匹配
- 编译的库文件没有被Flutter使用

**解决方案**：
```bash
# 1. 完全清理
cd /Users/niuzhidao/Documents/Program/t1mind/frontend/appflowy_flutter
flutter clean
rm -rf build/
rm -rf macos/build/
rm -rf .dart_tool/

# 2. 重新获取依赖
flutter pub get

# 3. 重新构建整个项目
cd ..
cargo make appflowy-flutter
```

### Q3: 编译失败

**检查步骤**：
1. 确认Rust工具链正常：`rustc --version`
2. 确认protoc插件安装：`which protoc-gen-dart`
3. 查看详细错误：
   ```bash
   cd /Users/niuzhidao/Documents/Program/t1mind/frontend/rust-lib
   cargo build -p dart-ffi --features="dart" --verbose
   ```
