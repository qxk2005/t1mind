# MCP 服务器显示问题修复完成 ✅

## 🐛 问题描述

在创建/编辑智能体的对话框中，"选择 MCP 服务器"部分显示：
> "没有激活的 MCP 服务器，请在设置中激活"

但实际上在 MCP 配置页面中已经添加了服务器（excel-server-mcp、知识库-mcp 等）。

## 🔍 问题原因

原来的代码逻辑是：
```dart
// 只显示激活的服务器 (isActive = true)
final activeServers = state.servers.where((s) => s.isActive).toList();

if (activeServers.isEmpty) {
  // 显示 "没有激活的 MCP 服务器"
}
```

问题在于：
- MCP 服务器可能已经添加到系统中
- 但 `isActive` 字段可能为 `false`（未激活状态）
- 导致用户无法在智能体配置中看到和选择这些服务器

## ✅ 修复方案

### 1. 移除 isActive 过滤

现在**显示所有已配置的 MCP 服务器**，不再过滤 `isActive` 状态：

```dart
// 🔧 修改：显示所有服务器，不再过滤 isActive
// 让用户可以选择任何已配置的服务器
final availableServers = state.servers;
```

### 2. 添加状态标签

为了让用户知道服务器的状态，在未激活的服务器名称旁边显示"未激活"标签：

```dart
title: Row(
  children: [
    if (server.icon.isNotEmpty) Text(server.icon),
    Expanded(child: FlowyText.medium(server.name)),
    // 🔧 新增：显示服务器状态标签
    if (!server.isActive) ...[
      Container(
        // 显示 "未激活" 标签
        child: FlowyText.regular('未激活', fontSize: 10),
      ),
    ],
  ],
)
```

## 📝 后端处理逻辑

后端的 `get_tools_from_selected_servers()` 方法会：

1. 接收选中的服务器 ID 列表
2. 尝试从这些服务器获取工具：
   - 如果服务器已激活且有缓存工具 → 使用缓存
   - 如果服务器已激活但无缓存 → 尝试连接并获取
   - 如果服务器未激活 → 记录警告日志，跳过该服务器

```rust
for config in server_configs {
  if !config.is_active {
    info!("[Tool Discovery] 跳过未激活的服务器: {}", config.name);
    continue;
  }
  // 获取工具...
}
```

所以即使前端允许选择未激活的服务器，后端也会智能地处理：
- 激活的服务器 → 获取工具 ✅
- 未激活的服务器 → 安全跳过 ⚠️
