## 🏗️ 核心实现

### 方法签名

```rust
pub async fn stream_answer_with_auto_multi_turn(
  &self,
  workspace_id: &Uuid,
  chat_id: &Uuid,
  question_id: i64,
  format: ResponseFormat,
  ai_model: AIModel,
  system_prompt: Option<String>,
  tools: Option<Vec<ToolDefinitionPB>>,
  tool_handler: Option<Arc<crate::agent::ToolCallHandler>>,
  agent_config: Option<Arc<crate::entities::AgentConfigPB>>,
  max_iterations: usize,
) -> Result<StreamAnswer, FlowyError>
```

### 核心流程

```
1. 检查是否有工具定义
   ↓ 有 → 继续
   ↓ 无 → 使用普通流式响应
   
2. 构建初始消息历史
   - system 消息（如果有）
   - user 消息
   
3. 进入多轮对话循环
   ├─ 调用 OpenAI API
   ├─ 流式解析响应
   ├─ 转发 Answer 内容给用户
   ├─ 检测 tool_calls
   │
   ├─ 如果没有 tool_calls
   │  └─ 结束循环，返回最终答案
   │
   └─ 如果有 tool_calls
      ├─ 显示：🔧 正在调用工具: xxx
      ├─ 执行工具
      ├─ 显示：✅ xxx 完成 (123ms)
      ├─ 将工具结果添加到消息历史
      ├─ 显示：🤔 正在综合分析结果...
      └─ 继续下一轮循环（回到步骤3）
   
4. 返回合并后的流
```

### 关键技术点

#### 1. 流式状态共享

使用 `Arc<Mutex<>>` 在流内外共享状态：

```rust
let accumulated_tool_call = Arc::new(tokio::sync::Mutex::new(Option::<OpenAIToolCall>::None));
let has_content_flag = Arc::new(tokio::sync::Mutex::new(false));

let tc_clone = accumulated_tool_call.clone();
let content_flag_clone = has_content_flag.clone();

// 在流中使用克隆的引用
*tc_clone.lock().await = Some(...);

// 流结束后访问原始引用
let result = accumulated_tool_call.lock().await.take();
```

#### 2. try_stream! 宏中的错误处理

不能使用 `return Err(...)`，而应使用 `Err(...)?`：

```rust
let s = try_stream! {
  if !resp.status().is_success() {
    let err = FlowyError::server_error()
      .with_context(format!("Request error: {}", resp.status()));
    Err(err)?;  // ✅ 正确
    // return Err(err);  // ❌ 错误
  }
};
```

#### 3. 生命周期处理

将 `agent_config: Option<&AgentConfigPB>` 改为 `Option<Arc<AgentConfigPB>>`：

```rust
// 修改前：生命周期问题
agent_config: Option<&crate::entities::AgentConfigPB>

// 修改后：使用 Arc 避免生命周期问题
agent_config: Option<Arc<crate::entities::AgentConfigPB>>

// 使用时：
tool_handler.execute_tool_call(&request, agent_config.as_ref().map(|c| c.as_ref())).await
```

#### 4. 部分移动问题

使用 `ref` 借用避免部分移动：

```rust
// 修改前：部分移动
if let Some(tc) = tool_call_opt {
  // tc 被移动
}
// tool_call_opt.is_none() // ❌ 错误：部分移动后无法使用

// 修改后：借用
if let Some(ref tc) = tool_call_opt {
  // tc 是借用，不移动
}
// tool_call_opt.is_none() // ✅ 正确：可以继续使用
```

如果未来支持多个独立工具调用，可以并行执行：

```rust
let futures: Vec<_> = tool_calls.iter()
  .map(|tc| tool_handler.execute_tool_call(tc, agent_config))
  .collect();

let results = futures::future::join_all(futures).await;
```

对于相同参数的工具调用，可以缓存结果：

```rust
let cache_key = format!("{}:{}", tool_name, arguments_hash);
```
